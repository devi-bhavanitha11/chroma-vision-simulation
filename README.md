# chroma-vision-simulation
CHROMA VISION:a browser-based proof-of-concept simulation of a personalised colour-assist wearable for colour vision deficiency.Compare simplified protan,deutan and tritan views with pattern-cue enhancement on images or live camera.Educational demo,not clinically validated.Team VoidX, 1st year information technology,Kumaraguru College of Technology
## Live demo
https://devi-bhavanitha11.github.io/chroma-vision-simulation/

## How to use
1. Choose a colour-vision profile
2. Choose an enhancement mode
3. Load an image or start the camera
